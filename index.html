The Chore Auction

Kids bid for chores. The lowest bid wins the job and earns those points. Points buy screen time. The arguing stops, because everyone chose.

1

Kids bid

Each kid says how few points they would take to do a chore. Bids stay secret.

2

Lowest bid wins

Once a week the auction closes on its own and picks a fair winner for every chore.

3

Do it, earn it

A parent checks the chore and taps Done. Points go in the bank for rewards.

Built to be fair

A limit on how many chores one kid can win, so nobody grabs everything by bidding 1.
A minimum pay for every chore that you set, so no chore is ever done for nothing.
Chores rotate, so the same kid does not get stuck with the same job every week.
Ties go to the kid with fewer chores.
No chore is left undone. Leftover jobs go to whoever has the fewest, at full pay.
Every point earned or spent is listed, so kids can see it is fair.

Private by design

Each family's information is kept in its own private file that only this app can open. Your family link is long and random. Parent actions need your PIN, which is stored scrambled and checked on the server, not in this page.

Adding your kids' tablets

No links to text and nothing to scan. On each kid's tablet or phone:

  1. Go to
  2. Tap Enter a join code
  3. Type the code from your Parent tab (tap Get a join code)

Each code works once and expires in 10 minutes, so it is useless to anyone else.

Add it to the home screen

iPhone or iPad: open the link in Safari, tap the Share button, then Add to Home Screen.

Android: open the link in Chrome, tap the three dots, then Add to Home screen.

Keep the link in the family

Anyone with the link can see your chores and place bids. Only someone with your PIN can approve chores, give points, or change settings.
